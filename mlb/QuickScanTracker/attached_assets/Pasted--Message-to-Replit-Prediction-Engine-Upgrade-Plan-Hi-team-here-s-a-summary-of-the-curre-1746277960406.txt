## ✅ Current System Strengths (Keep These)

* **Stat-based win model** using batting avg, ERA, OPS, and home field
* **Bayesian calibration** for win probability and runs
* **Confidence scoring** based on feature availability (pitching, weather, etc.)
* **Ensemble blending** using CatBoost + simulation
* **Betting value logic** that compares implied vs. model probability (expected value)
* **Run prediction model** with MLB score constraints (2–8 runs per team)
* **No mock/static data** – everything based on real API input only

* Add **SHAP value logging** to explain why the model favors each team

### 🔹 Enhanced Simulation & Correlation Tools

* Use simulated score distributions to:

### 🔹 Performance Tracking

* Log **daily Brier score** and **ROI vs. closing line**
* Track model accuracy where edge > 5% to validate real-world returns

### 🔹 Market Movement Insight

* Detect **reverse line movement** where public % and sharp money disagree
* Compare model's early prediction to line move direction (was it ahead?)
