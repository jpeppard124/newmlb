About the MLB Betting Engine

Project Purpose

This system is designed to create a high-accuracy, data-driven MLB betting engine that:

  • Predicts what will actually happen in games based on real stats, not just sportsbook lines
  • Surfaces mispriced or overlooked betting opportunities (e.g., games the book has undervalued)
  • Combines both real-time feeds (odds, weather) and scheduled insights (lineups, advanced stat pulls)
  • Applies advanced prediction methods such as Bayesian calibration, ensemble models, simulation, and correlated outcome analysis
  • Uses strictly live or historical API-fed data only — no static, mock, or fictional data in testing or production

Key Principles

Model Probability First

We focus on accurately predicting game outcomes based on real data, then compare to sportsbook pricing. This approach allows us to spot true value rather than just reacting to line movements.

Calibrated Predictions

Our models use Bayesian calibration to ensure that a 70% win probability actually wins 70% of the time. This calibration is essential for proper bankroll management and expected value calculations.

Sharp-Aware Edges

We track both public and sharp betting patterns to identify where the most informed money is going. Combined with our statistical models, this creates a powerful predictor of future line movements.

Data Simulation & Correlation

Our system runs thousands of game simulations to model interdependencies between outcomes. This helps identify valuable parlay opportunities where the true joint probability exceeds the implied odds.

System Components

  • Node.js backend pulls and stores odds from both OddsAPI and Discovery Lab
  • Python layer uses Statcast (xwOBA, barrel %, etc.) to detect high-leverage player trends
  • WeatherAPI adds forecast-based context (e.g., wind boost for overs)
  • SQL Database stores historical predictions, results and performance metrics
  • Prediction engine includes Bayesian calibration, SHAP analysis, ensemble modeling
  • Correlation modeling for parlay optimization and related outcome analysis
  • Performance logging for daily model outcomes (predicted vs actual, ROI by bet type)
  • Contrarian betting filters and sharp-vs-public signals

Data Integrity

All data is sourced directly from live APIs or past historical feeds. No mock or manually created records are permitted. This ensures all logic and models remain accurate, trustworthy, and production-safe.

Data Refresh Cycles
  • Odds: Updated every 15 minutes
  • Weather: Updated hourly
  • Statistical data: Updated every 12 hours
  • Model performance: Updated daily
Technical Details
  • Python backend with Flask web framework
  • SQL database for data storage
  • Pandas & NumPy for data analysis
  • CatBoost & scikit-learn for modeling
  • SHAP for model interpretation
